# Engineer Knowledge

Personal engineering knowledge base focused on Linux, DevOps, DevSecOps, infrastructure, and automation.

Built while learning and practicing through real home-lab tasks.

## Principles

- Learn by doing
    
- Understand before automating
    
- Security by design
    
- Keep systems simple
    
- Document reusable knowledge
    
- Practice before production
    

## Structure

- `00.Inbox` — temporary notes and ideas
    
- `10.Projects` — active projects
    
- `20.Areas` — areas of continuous learning
    
- `30.Resources` — reference knowledge
    
- `35.Practice` — hands-on exercises
    
- `40.Archive` — inactive or outdated material
    
- `50.Maps` — navigation and knowledge maps
    
- `90.Templates` — reusable note templates
    

## Goal

Build a practical engineering knowledge base that grows together with real DevOps and DevSecOps experience.
