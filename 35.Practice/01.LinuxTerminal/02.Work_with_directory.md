# Work with Directories — Practice

## Objective

Learn to create, copy, move, and safely remove directories.

---

# Level 1 — Basics

## Create Directories

- [ ] Create a directory named `test`
- [ ] Create three directories manually
- [ ] Create nested directories using `mkdir -p`

Expected result

```text
test/
└── project/
    └── logs/
```

## Remove Directories

- [ ] Remove an empty directory using `rmdir`
