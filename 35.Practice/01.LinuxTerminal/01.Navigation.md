# Navigation — Practice

## Level 1 — Basic Navigation

Without looking at `Areas`:

-  Show your current directory.
    
-  Go to your home directory.
    
-  Go to `/etc`.
    
-  Return to your home directory.
    
-  Go to the parent directory.
    
-  Return to the previous directory.
    
-  List files in the current directory.
    
-  List hidden files.
    

### Question

Explain:

```text
.
..
~
/
```

## Level 2 — Paths

Create:

```text
navigation-kata/
└── project/
    ├── config/
    ├── logs/
    └── data/
```

Then:

-  Enter `project`.
    
-  Go to `config` using a relative path.
    
-  Go to `logs` without returning home.
    
-  Go to `/etc` using an absolute path.
    
-  Return to `project`.
    
-  Explain the difference between absolute and relative paths.

## Level 3 — Inspect Structure

-  Include hidden files.

What is the practical difference between:

```text
ls -R
```

## Final Challenge

Without looking at `Areas`:

1. Determine your current location.
    
2. Inspect the current directory.
    
3. Show hidden files.
    
4. Inspect the directory tree.
    
5. Move using absolute paths.
    
6. Move using relative paths.
    
7. Find which directories consume the most disk space.
    
8. Explain where you would search for configs, logs, and application data.
    

**Goal:** connect to an unfamiliar Linux machine and confidently understand where you are and where to go.
