# Owners & Permissions — Practice

## Level 1 — Read Permissions

Create a workspace:

```bash
mkdir -p ~/permission-kata
cd ~/permission-kata
touch config.txt
```

-  Check permissions of `config.txt`.
    
-  Identify the owner.
    
-  Identify the group.
    
-  Identify permissions for owner, group, and others.
    
-  Check your current user.
    
-  Check your UID, GID, and groups.
    

### Question

Explain:

```text
-rw-r--r--
```

## Level 2 — chmod

Create:

```bash
touch deploy.sh
```

Without looking at `Areas`:

-  Give the owner read/write permissions and everyone else read-only access.
    
-  Verify the result.
    
-  Add execute permission to `deploy.sh`.
    
-  Verify the result.
    
-  Set permissions to `755`.
    
-  Convert `755` back to symbolic form (`rwx...`).
    

### Questions

What do these mean?

```text
644
600
755
700
```

## Level 3 — Directory Permissions

Create:

```bash

```

-  Check permissions of `private`.
    
-  Set directory permissions to `700`.
    
-  Verify the result.
    
-  Explain what `r`, `w`, and `x` mean for a **directory**.

## Level 4 — Ownership

Create:

```bash

```

-  Check its owner and group.
    
-  Check which groups your user belongs to.
    
-  Change the group to one you belong to.
    
-  Verify the change.
    
-  Restore the original group.

## Level 5 — DevOps Scenario

Create:

```bash
mkdir -p app/config
touch app/config/app.conf
touch app/deploy.sh
```

Configure it so that:

-  `deploy.sh` is executable.
    
-  `app.conf` has `644` permissions.
    
-  `app/` has `755` permissions.
    
-  Check ownership of all files.
    
-  Verify everything with one directory listing.

## Level 6 — Troubleshooting

Inspect:

```bash
namei -l ~/permission-kata/app/config/app.conf
```

-  Identify every directory in the path.
    
-  Check the permissions of each directory.
    
-  Identify where traversal permission (`x`) is required.
    

### Scenario

An application returns:

```text
Permission denied: /var/www/app/config.yml
```

Without changing anything, explain what you would check first.
