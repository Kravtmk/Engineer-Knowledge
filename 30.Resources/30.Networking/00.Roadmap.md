# Networking Roadmap — DevOps

## 🟢 Junior — Understand the packet

Goal:
Understand how traffic gets from one host to another
and diagnose basic connectivity problems.

### L1/L2
- [ ] Network interface
- [ ] MAC address
- [ ] LAN
- [ ] ARP
- [ ] Switch
- [ ] Broadcast domain
- [ ] VLAN basics
- [ ] Access vs trunk

### L3
- [ ] IPv4
- [ ] CIDR /24
- [ ] CIDR /25 /26
- [ ] Subnet
- [ ] Network / host / broadcast address
- [ ] Gateway
- [ ] Routing basics
- [ ] Longest Prefix Match

### Network services
- [ ] DHCP concept
- [ ] DNS
- [ ] NAT

### L4
- [ ] TCP
- [ ] UDP
- [ ] Ports
- [ ] TCP handshake
- [ ] LISTEN / ESTABLISHED

### Security
- [ ] Firewall basics
- [ ] allow / deny
- [ ] bind address

### Tools
- [ ] ip addr
- [ ] ip route
- [ ] ip neigh
- [ ] ping
- [ ] traceroute / tracepath
- [ ] ss
- [ ] nc
- [ ] dig
- [ ] curl networking
- [ ] tcpdump / Wireshark

### Junior DoD

Given:

Client → DNS → network → server:port

I can determine where connectivity fails.


## 🟡 Middle — Build the network

Goal:
Design and troubleshoot networking for real infrastructure.

- [ ] VLAN design
- [ ] Access / trunk
- [ ] Inter-VLAN routing
- [ ] Static routes
- [ ] Linux routing
- [ ] nftables
- [ ] Reverse proxy
- [ ] TLS
- [ ] Docker networking
- [ ] Kubernetes networking
- [ ] Service / Ingress
- [ ] NetworkPolicy
- [ ] VPN / Tailscale
- [ ] Packet capture analysis
- [ ] MTU basics

### Middle DoD

I can design and troubleshoot:

Internet
  ↓
Router / Firewall
  ↓
VLAN / Subnet
  ↓
Linux host
  ↓
Docker / K3s
  ↓
Reverse Proxy / Ingress
  ↓
Application


## 🔴 Senior — Design the network

Goal:
Understand architecture, failure domains and scale.

- [ ] Advanced routing concepts
- [ ] OSPF concepts
- [ ] BGP concepts
- [ ] High availability
- [ ] Load balancing
- [ ] Multi-site networking
- [ ] Site-to-site VPN
- [ ] Cloud networking
- [ ] AWS VPC / routing / security groups
- [ ] Kubernetes CNI architecture
- [ ] DNS architecture
- [ ] Zero Trust concepts
- [ ] Observability
- [ ] Capacity / failure-domain design

### Senior DoD

I can design a network,
explain why it is designed that way,
predict failure modes,
and troubleshoot it systematically.
