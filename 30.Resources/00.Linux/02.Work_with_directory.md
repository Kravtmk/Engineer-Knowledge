# Work with Directories

## Overview

Directories organize files into a hierarchical structure.

Managing directories is a fundamental Linux skill used to:

- organize projects
- deploy applications
- manage configuration files
- maintain clean environments

---

## Create Directories

### mkdir

Create a new directory.

```bash
mkdir project
```

---

### mkdir -p

Create nested directories.

```bash
mkdir -p projects/devops/ansible
```

Result

```text
projects/
└── devops/
    └── ansible/
```

---

## Remove Directories

### rmdir

Remove an empty directory.

```bash
rmdir project
```

---

### rm -r

Remove a directory and all its contents.

```bash
rm -r project
```

> Use with caution. The directory and all files inside it will be permanently removed.

---

### rm -ri

Remove recursively with confirmation.

```bash
rm -ri project
```

Recommended when working on production systems.

---

## Copy Directories

### cp -r

Copy a directory recursively.

```bash
cp -r project backup
```

---

### cp -a

Archive mode.

Preserves:

- permissions
- ownership
- timestamps
- symbolic links

```bash
cp -a project backup
```

Use when migrating applications or creating backups.

---

## Move or Rename

### mv

Move or rename a directory.

Rename

```bash
mv project project-old
```

Move

```bash
mv project /opt/
```

---

## Directory Information

### ls -ld

Display information about the directory itself.

```bash
ls -ld project
```

Example

```text
drwxr-xr-x 2 alex alex 4096 Jul 30 project
```

---

## Common Use Cases

Create a project structure

```bash
mkdir -p ~/projects/ansible/{roles,inventory,playbooks}
```

Backup a directory

```bash
cp -a app app.backup
```

Rename a project

```bash
mv app app-old
```

Delete a temporary directory

```bash
rm -r tmp
```

Force Delete
```
rm -rf
```


---

## Best Practices

- Use `mkdir -p` for nested directories.
- Prefer `cp -a` when preserving metadata is important.
- Verify the current directory with `pwd` before using `rm -r`.
- Use `rm -ri` on production systems.
- Double-check the target path before deleting data.
