# Navigation

## Overview

Navigation is the ability to move through the Linux filesystem efficiently.

It is one of the first skills every Linux and DevOps engineer must master.

Without navigation you cannot:

- inspect configuration files
- analyze logs
- troubleshoot services
- manage applications
- understand an unfamiliar system

---

## Core Commands

| Command  | Description                     |
| -------- | ------------------------------- |
| `pwd`    | Print current working directory |
| `ls`     | List directory contents         |
| `ls -l`  | Long listing format             |
| `ls -la` | Include hidden files            |
| `cd`     | Change directory                |
| `tree`   | Display directory structure     |
| ncdu     |                                 |

---

## Paths

### Absolute Path

Starts from the root directory.

Example:

```text
/etc/nginx/nginx.conf
```

---

### Relative Path

Starts from the current directory.

Example:

```text
../logs
./script.sh
```

---

## Special Directories

| Symbol | Meaning |
|---------|---------|
| `.` | Current directory |
| `..` | Parent directory |
| `~` | User home directory |
| `/` | Root directory |

---

## Navigation Examples

Go to your home directory

```bash
cd
```

or

```bash
cd ~
```

Go to the root directory

```bash
cd /
```

Go to the parent directory

```bash
cd ..
```

Return to the previous directory

```bash
cd -
```

Change to an absolute path

```bash
cd /etc/docker
```

Change to a relative path

```bash
cd ../logs
```

---

## Navigation Workflow

When connecting to a Linux server:

1. Identify your current location.

```bash
pwd
```

2. Inspect the current directory.

```bash
ls -la
```

3. Move to the required location.

```bash
cd /etc
```

4. Continue exploring the filesystem.
