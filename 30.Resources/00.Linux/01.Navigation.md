# Navigation

## Overview

Linux uses a single filesystem tree starting from:

```text
/
```

Navigation means understanding:

- where you are
    
- what is around you
    
- how to move through the filesystem
    
- how directories relate to each other
    

---

## Current Directory

### pwd

`pwd` means **print working directory**.

It shows your current location.

```bash
pwd
```

Example:

```text
/home/alex/projects
```

---

## List Directory Contents

### ls

Show files and directories in the current directory.

```bash
ls
```

### ls -la

Show detailed information, including hidden files.

```bash
ls -la
```

Example:

```text
drwxr-xr-x alex alex 4096 Aug 17 .
drwxr-xr-x alex alex 4096 Aug 16 ..
-rw-r--r-- alex alex  220 .bashrc
```

It shows information such as:

- permissions
    
- owner
    
- group
    
- size
    
- modification time
    
- hidden files
    

---

## Recursive Listing

### ls -R

List the current directory and recursively show what is inside its subdirectories.

```bash
ls -R
```

Example:

```bash
ls -R project
```

Output:

```text
project:
config
logs

project/config:
app.conf

project/logs:
app.log
```

This helps inspect an entire directory structure.

## Navigate with cd

`cd` means **change directory**.

### Home

```bash
cd ~
```

`~` represents the current user's home directory.

For example:

```text
/home/alex
```

### Root

```bash
cd /
```

`/` is the root of the Linux filesystem.

### Parent

```bash
cd ..
```

`..` represents the parent directory.

### Current Directory

```text
.
```

`.` represents the current directory.

### Previous Directory

```bash
cd -
```

Returns to the previous working directory.

---

## Absolute and Relative Paths

An **absolute path** starts from `/`.

```text
/etc/nginx/nginx.conf
```

Example:

```bash
cd /etc/nginx
```

A **relative path** starts from your current location.

```text
../logs
```

Example:

```bash
cd ../logs
```

---

## tree

`tree` displays directories and files visually as a hierarchy.

```bash
tree
```

Example:

```text
project
├── config
│   └── app.conf
├── logs
│   └── app.log
└── README.md
```

### Limit Depth

```bash
tree -L 2
```

`-L` controls how many directory levels are displayed.

This is useful when a project contains hundreds or thousands of files.

---

## ncdu

`ncdu` is an interactive disk usage analyzer.

```bash
ncdu
```

It allows you to navigate directories and quickly see which files and directories consume disk space.

Analyze a specific location:

```bash
ncdu /var
```

Typical DevOps use:

- investigate a full disk
    
- find large logs
    
- inspect application data
    
- inspect user directories

## Typical DevOps Locations

```text
/etc        System and service configuration
/var/log    Logs
/var/lib    Application and service data
/home       User home directories
/opt        Third-party applications
/usr/local  Locally installed software
/tmp        Temporary files
```

## Key Concept

When you connect to an unfamiliar Linux server, navigation is not only moving between directories.

You are building a mental map:

```text
Where am I?
    ↓
What is here?
    ↓
What is inside?
    ↓
Where is the configuration?
    ↓
Where are the logs?
    ↓
Where is the application data?
```
