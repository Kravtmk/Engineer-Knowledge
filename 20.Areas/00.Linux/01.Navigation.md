# Navigation

## Current Location

```bash
pwd
```

## List

```bash
ls
```

```bash
ls -la
```

Recursive:

```bash
ls -R
```

## Navigate

Home:

```bash
cd ~
```

Root:

```bash
cd /
```

Parent:

```bash
cd ..
```

Previous directory:

```bash
cd -
```

Absolute path:

```bash
cd /var/log
```

Relative path:

```bash
cd ../logs
```

## Tree

```bash
tree
```

Show 2 levels:

```bash
tree -L 2
```

Show 4 levels:

```bash
tree -L 4
```

Include hidden files:

```bash
tree -a
```

## Disk Usage

Directory size:

```bash
du -sh directory/
```

Directories by size:

```bash
du -h --max-depth=1
```

Interactive disk usage:

```bash
ncdu
```

Specific location:

```bash
ncdu /var
```

## Common Locations

```text
/etc        configs
/var/log    logs
/var/lib    application data
/home       user data
/opt        third-party software
/usr/local  custom software
/tmp        temporary data
```
