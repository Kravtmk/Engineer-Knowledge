# Work with Directories

## Create

Create a directory

```bash
mkdir project
```

Create nested directories

```bash
mkdir -p project/{logs,config,data}
```

Example

```text
project/
├── config/
├── data/
└── logs/
```

---

## Remove

Remove an empty directory

```bash
rmdir project
```

Remove a directory recursively

```bash
rm -r project
```

Remove recursively with confirmation

```bash
rm -ri project
```

Force remove (Danger)

```bash
rm -rf project
```

---

## Copy

Copy a directory

```bash
cp -r project backup
```

Copy while preserving metadata

```bash
cp -a project backup
```

---

## Move / Rename

Rename

```bash
mv project project-old
```

Move

```bash
mv project /opt/
```

---

## Directory Information

Directory permissions

```bash
ls -ld project
```

Directory size

```bash
du -sh project
```

Largest directories

```bash
du -h --max-depth=1
```

Interactive disk usage

```bash
ncdu
```

Analyze a specific directory

```bash
ncdu /var
```

---

## Common DevOps Examples

Create an Ansible project

```bash
mkdir -p ansible/{inventory,playbooks,roles,group_vars,host_vars}
```

Create a Docker project

```bash
mkdir -p app/{docker,compose,logs,data}
```

Backup before deployment

```bash
cp -a app app.backup
```

Clean temporary files

```bash
rm -rf /tmp/*
```

---

## Safety

Check current directory

```bash
pwd
```

List directory contents

```bash
ls -la
```

Confirm before deleting

```bash
rm -ri project
```

Never execute

```bash
rm -rf /
```
