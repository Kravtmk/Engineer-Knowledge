## Check Permissions

Show permissions, owner, and group.

```bash
ls -l
```

Include hidden files.

```bash
ls -la
```

Check a specific directory itself.

```bash
ls -ld /var/log
```

Example:

```text
-rw-r--r-- 1 alex developers 1200 Aug 16 app.conf
```

```text
-           file
rw-         owner permissions
r--         group permissions
r--         others permissions
alex        owner
developers  group
```

---

## chmod

Change permissions.

```bash
chmod 644 file.txt
```

```bash
chmod 755 script.sh
```

Add execute permission.

```bash
chmod +x script.sh
```

Remove write permission.

```bash
chmod -w file.txt
```

Recursive:

```bash
chmod -R 755 directory/
```

---

## Permission Numbers

```text
r = 4
w = 2
x = 1
```

Common permissions:

```text
644  rw-r--r--   regular file
600  rw-------   private file
755  rwxr-xr-x   executable / directory
700  rwx------   private directory
```

---

## chown

Change owner.

```bash
sudo chown alex file.txt
```

Change owner and group.

```bash
sudo chown alex:developers file.txt
```

Recursive:

```bash
sudo chown -R alex:developers directory/
```

---

## chgrp

Change group.

```bash
sudo chgrp developers file.txt
```

---

## Check User / Groups

Current user:

```bash
whoami
```

User and group IDs:

```bash
id
```

Groups:

```bash
groups
```

Check another user:

```bash
id nginx
```

---

## Common DevOps Examples

Make a script executable:

```bash
chmod +x deploy.sh
```

SSH private key:

```bash
chmod 600 ~/.ssh/id_ed25519
```

SSH directory:

```bash
chmod 700 ~/.ssh
```

Change application ownership:

```bash
sudo chown -R nginx:nginx /var/www/app
```

Check permissions through the entire path:

```bash
namei -l /var/www/app/config.yml
```

---

## Quick Diagnosis

```bash
ls -la
id
namei -l /path/to/file
```

For `Permission denied`, check:

```text
1. Owner
2. Group
3. rwx permissions
4. Parent directory permissions
```
