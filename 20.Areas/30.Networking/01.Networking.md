# Networking

## L2
- MAC — interface address inside a local L2 network
- Switch — connects devices inside a LAN
- ARP — IPv4 → MAC
- VLAN — separates one L2 infrastructure into isolated networks

## L3
- IP — identifies an interface in an IP network
- Subnet — defines which IP addresses are local
- Gateway — next L3 hop to another network
- Router — routes traffic between networks

## L4
- TCP — reliable connection-oriented transport
- UDP — connectionless transport
- Port — identifies a service/process endpoint

## Core services
- DHCP — gives hosts IP, mask, gateway and DNS
- DNS — name → IP
- NAT — translates addresses
- Firewall — allows/denies traffic
