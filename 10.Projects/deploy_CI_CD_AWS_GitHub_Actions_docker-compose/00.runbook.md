# AWS EC2 + Docker Compose CI/CD — Runbook

## Goal

Deploy a containerized application to AWS EC2 using GitHub Actions.

```text
git push
   ↓
GitHub Actions
   ↓
Docker build
   ↓
GHCR
   ↓
GitHub OIDC
   ↓
AWS IAM
   ↓
AWS Systems Manager
   ↓
EC2
   ↓
Docker Compose
   ↓
MyApp
````

## Security Model

```
GitHub Actions
    ↓ OIDC
AWS IAM Role
    ↓ temporary credentials
AWS Systems Manager
    ↓
EC2
```

Principles:

- no long-lived AWS credentials in GitHub
- no public SSH required for GitHub Actions
- IAM least privilege
- repository and branch restricted OIDC trust
- immutable Git SHA image versions
