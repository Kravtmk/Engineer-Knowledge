# Ansible Repository

The Ansible configuration is maintained in a separate repository:

https://github.com/Kravtmk/ansible-infra

This keeps infrastructure configuration separate from the application deployment repository.

Architecture:

```text
Engineer workstation
        ↓
Ansible
        ↓ SSH
Ubuntu VM / EC2
        ↓
Server configuration
        ↓
Docker
```

---

# What Ansible Configures

The Ansible repository is responsible for preparing the server environment.

Typical configuration includes:

```text
base system configuration
        ↓
required packages
        ↓
Docker
        ↓
Docker Compose
        ↓
deployment-ready host
```

The application itself is not deployed by Ansible in this project.

Application deployment is handled by:

```text
GitHub Actions
        ↓
AWS Systems Manager
        ↓
Docker Compose
```

This separates:

```text
Server provisioning/configuration
              from
Application deployment
```

# Workflow

From the Ansible control machine:

```bash
git clone https://github.com/Kravtmk/ansible-infra.git
cd ansible-infra
```

Configure the inventory for the target server.

Test connectivity:

```bash
ansible all -m ping
```

Run the playbook:

```bash
ansible-playbook site.yml
```

> Exact inventory groups, variables and roles depend on the current `ansible-infra` repository configuration.

---

# Verify

On the target server:

```bash
docker --version
docker compose version
```

Check Docker:

```bash
sudo docker run --rm hello-world
```

Expected:

```text
Docker installed          ✅
Docker Compose installed  ✅
Docker daemon running     ✅
Server ready for deploy   ✅
```
